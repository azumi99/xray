# GraphQL Folder Structure

This folder contains all GraphQL related files for the AWB X-Ray application.

## Folder Structure

- `./types/` - GraphQL type definitions
- `./queries/` - GraphQL query operations
- `./mutations/` - GraphQL mutation operations
- `./subscriptions/` - GraphQL subscription operations
- `./schema.graphql` - The main GraphQL schema definition
- `./client.ts` - Apollo Client configuration

## Usage

The GraphQL operations are organized by type:
- Queries: For fetching data
- Mutations: For creating, updating, or deleting data
- Subscriptions: For real-time data updates

## Schema

The main schema defines the types and operations available in the GraphQL API.
